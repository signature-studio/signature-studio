## 5 止まった場所(静的な解析)

- 戻り先 0x9215608 は PEQ2 の RVA 0x215608。pdata の関数 0x2155b0〜0x215653 の中。
- 呼び出し: `0x215606: call qword ptr [rax]`、その直前 `0x215606 - 7: mov rax, qword ptr [rip + 0x13ad9a]`。つまり、グローバル(RVA 0x3500A0)の値をオブジェクトとして読み、そのスロット 0 を呼ぶ(Delphi のインターフェース呼び出しの形)。スロット 0 が 0 だった。
- 0x3500A0 の .data の静的な初期値は 0x73a2e4(ポインタではない。数値)。
- 0x3500A0 を参照する pdata の関数は 7 件の読み出しだけ(関数 0x2eddc0 の中。書き込みの直接参照は見つからなかった)。書き込みは、ポインタ経由などの別の経路と読める(未確認)。
- 0x3500A0 の値を決める関数(オブジェクトの生成)は未特定。
