## 2 決定(分類つき)

| 決定 | 分類 | 根拠 |
|---|---|---|
| 単位を生成 C の書き出し時に直接書く(生成 C を 1 度ファイルに出して読み直す split_bytes.py の工程を消す) | 通信・変換の削減 | `evidence/R6-25.md` §5 C1。単位の内容は split_bytes.py と同じ(下の §3) |
| 単位の境界は、一覧の本体を除く前の大きさで決める(split → strip の順と同じ境界) | 整備(境界を従来と一致させる) | 境界を変えると、一覧の除去の前後で単位の内容が変わり、旧経路と比べられない |
| 一覧の本体の除去は、書き出しの時に行う(strip_units.py の 61 回の実行を消す)。除くのは「void f_X(void)」から最初の「}」の行まで。後ろの空行は残す | 変換の削減 | strip_units.py の挙動(30 行)の写し。§3 で同じバイト列 |
| 統合表は `PREFIX-tables.txt` に、split_mod.py と同じ中身で書く(表の行は関数の外) | 整備 | main の指示(インターフェース (1))。C2 の一部 |
| R・FL・X の宣言は `#ifndef FLE_LOWREGS`(X は `FLE_LOWREGS_X`)で囲んで書く。lowregs.py の囲みと同じバイト列 | 変換の削減(lowregs.py の工程を消す準備) | **依頼 (3) からの逸脱**: 定義を出さない形にすると、`lift/harness/parity/native-build.sh` が読む WSRC の単位(FLE_LOWREGS の無い native の clang でコンパイル)で R が未定義になり、native のパリティが壊れる(読み: 同スクリプトの 18 行目)。囲みなら native は宣言を使い、wasm は fle_runtime.h が両マクロを定義するので宣言が入らない(`fle_runtime.h` の 10〜15 行)。main に 19:4x に返信済み(oc-msg の msg_1e3ef7e39001gbxTx7Ahk2RRno) |
