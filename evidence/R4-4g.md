## 3. 番号 18 が Unlock を呼ぶスレッドとして記録されていること

- 記録の仕組み: `fle_dsound.c:1138-1144` の Unlock の中で `fle_audio_unlock_note` が呼ばれる。`fle_audio_transport.c:163` が `mixer_thr = (int)fle_thread_current()` を記録し、`pulses[].mixer` として送られる(`fle_audio_transport.c:156`)。値は「直近の Unlock を呼んだスレッド」で、呼び出し元の全部ではない。
- データ(4 run とも同じ形): `mixer` は −1 → 7 → 18 と変わり、18 のまま終わる。切り替わりは mix0-1 で −33.8 s、mix0-2 で −34.1 s、mix20-1 で −33.9 s、mix20-2 で −33.8 s。これは番号 18 が最初に動いた時刻(§2 の表)とほぼ同時(mix20-1 で −33.9 s と −34.4 s、差 0.5 s 以内)。
- 旧記録との対応(出典のみ。この作業では再確認していない): `docs/archive/decisions/0276-p3-real-cpu-levers.md:8` と `:105` は、別の実行で「スレッド 18 の Unlock」を数えている。
