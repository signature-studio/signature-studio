## 2 インターフェース

```
fe-lift gen-all --modules TSV --fle-args FILE --host DIR --out DIR --split-bytes N [--omit-list FILE] [--extra-rows FILE]
```

main の指示の形との違い: `--host`(原本の置き場。FLEngine と各モジュールの原本を読むために必要。指示の形には無かった)と `--fle-args`(FLEngine の引数の 1 行。指示の形では直書きだった)を足した。TSV は 5 列(realmod 名・原本のパス(`--host` からの相対)・基底・lift の引数・realmod のパス接尾辞。接尾辞は空でもよい)。

出力(DIR): `dll/<原本の名前>.<基底 16 進>.dll`(rebase 済み)、`src/fle-NN.c`・`src/fle-tables.txt`、`src/mK-NN.c`・`src/mK-tables.txt`(K は 1〜9)、`common.c`、`realmod.c`。

`--extra-imports` は、プロセス全体の表(`set_extra`。一度しか設定できない)に 1 回だけ設定する。FLEngine と各モジュールの引数の中の値が同じファイルであることを確かめ、違えばエラーにする。
