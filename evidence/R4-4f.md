## 1. 定義と式

- 区間: 再生開始(`marks.play`)から 0〜150 s(R4-4d の 8 回。`r44e-threads.py` の 15 窓と同じ区間)。R4-3 の 6 回は 0〜150 s と 150〜300 s の 2 区間。
- 値: `pulses[].threads[i]` の `a`(実行 ms の累積)と `c`(実行回数の累積)を、`epoch` に対して線形補間する(`r44e-threads.py` の `interp` と同じ式)。区間の Δ = 終端 − 始端。
- 対照: 0 回/秒の 2 回の平均。差 = その run − 対照。0 回/秒の 2 行は対照の平均との差なので、構成上、符号が反対で大きさが同じになる。
- 移動 1 回あたり: 差 ÷ 台本の予定 move(5 回/秒 750、10 回/秒 1,500、20 回/秒 3,000。150 s × 頻度。`evidence/R4-4d.md` §1)。0 回/秒は割らない。
- 並べ方は 2 つ: 0〜150 s の経過時間で揃える(§3.2・§3.3 の「150 s あたり」)と、台本の移動回数で割る(§3.1・§3.3 の「移動 1 回あたり」)。`wallS` は 0 回/秒 約 150.4 s、20 回/秒 約 187.6 s(`evidence/R4-4d.md` §3.1)で違うが、0〜150 s の区間はどの回も同じ長さ。
- 選んだスレッド: 0・18・対照の Δa 上位 5・各 run の Δa 上位 5 の和集合。スレッド 1 は Δa が全 run で 0 のため、上位 5 の同順位の並びで残りの枠に入った(番号順の結果。意味はない)。
