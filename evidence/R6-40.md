## 3. 直した後
- 対象: origin/main の最新 `171d5744053def08946f3fe0fd5ca4eaad591358`(`git pull --ff-only origin main` の後の HEAD。先頭 40 字)。
- 手順: 履歴を持つ clone(`git clone --no-checkout --shared <共通の .git> <一時の木>`)を作り、`git checkout 171d5744053def08946f3fe0fd5ca4eaad591358` で木を取り出して、その木で検査を実行した。`git archive` の木は履歴が無く、commit 付きの参照が「その commit に無い」と出るため、この手順にした。
```
$ cd <一時の木> && bash scripts/check-consistency.sh
KIND  WHERE                                 WHAT                                  WHY
consistency: 0 finding(s)
$ echo rc=$?
rc=0
$ git status --short | wc -l
0
```
- 作業の木(index = この commit の中身)でも同じく `consistency: 0 finding(s)`、rc 0。
- commit 付きの参照(`<commit>:<path>`・`<commit>^:<path>`)は、検査が `git cat-file --batch-check` で存在を確かめる。0 件は、そのすべてが履歴にあることを示す。
