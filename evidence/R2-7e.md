## 予測(測定前に書いた)

- 組み合わせ A = E13 の wasm・glue・dll と base の seed。組み合わせ B = base の wasm・glue・dll と E13 の seed。
- seed の違いが base − E13 の差と一緒に動くなら、A は E13 より遅い側に、B は base より速い側に出る。一緒に動かないなら、A は E13 に、B は base に近い。
- n=10 の中央値で並べ、差の大きさは書く。この測定の範囲の事実として書く(判定はしない)。
- 測定の順序: 1 周 = E13 → A → base → B の順、10 周。run 数は 4 bundle × 10 = 40。各回は直列・前面で実行し、静かさの条件(直前の 1 分 loadavg > 8、または I/O pressure の avg10 ≠ 0 の回は数えず撮り直す)を満たす回だけを数える。
- 起動確認(n=1 ずつ)の 2 回は結果に数えない。
