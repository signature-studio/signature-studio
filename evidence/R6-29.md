### 1.1 hybrid-n0(stage_hybn0 の写し)
`fe-wasmgen hybrid-n0 --modules TSV --lists DIR --dll-dir DIR --args n0.args --work DIR --out-rsp FILE`

- 各モジュール(一覧が空か無いモジュールは飛ばす)を、ダミー番地の引数で 1 モジュールの fe-wasmgen に渡す(`--hybrid-only`・`--report` を付ける)。
- 出力の検査: 一覧の関数が status ok で出ているか(chk_lowered.py と同じ。欠けたら止まる)。
- module c の function import の名前を集め、重複を除いて `-Wl,--export-if-defined=NAME` の行にして exports.rsp に書く。

### 1.2 hybrid(stage_hybrid の写し。ガードは書いていない)
`fe-wasmgen hybrid --modules TSV --lists DIR --dll-dir DIR --args h.args --work DIR --link-map FILE --c-part FILE --out FILE --wasm-opt BIN --wasm-opt-args FILE --wasm-merge BIN --features FILE`

- link map から番地を読む(grep の形と同じ。`fle_teb` `fle_mxcsr` `fle_hyb_buf` `fle_progress_count` `fle_progress_limit` `fle_landing_top` `fle_dispatch_hook` と、`fle_ctx` の TLS の offset)。見つからなければ止まる。
- 各モジュールを、番地つきの引数で fe-wasmgen に渡し、一覧の検査、wasm-opt(引数は wasm-opt.args のファイル)。
- wasm-merge の 1 回目(直接モジュールを 1 つに。名前 d<モジュール>)、2 回目(C 部分へ。env と c)。
- 最終の検査: module c の function import 0 件、env の f_ の function import 0 件。通ったら --out に書く。
