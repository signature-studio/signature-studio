## 目的
worker `<ses_…>` の報告と、実際の差分・実行結果が一致するか検証する。完了を宣言してよいか(`AGENTS.md` §9)の判定材料を出す。

## 入力
- worker の報告(全文または要点): <貼る。長いときはファイルのパス>
- 作業木: `<パス>`(worker が報告した作業木)、基点のコミット: <sha または `HEAD~N`>
- worker に出した依頼の完了条件: <task-template の「完了条件」をそのまま貼る>

## やること(上から順に実行し、各コマンドの出力を報告に貼る)
1. 差分の突き合わせ
   ```
   git -C <作業木> status --short
   git -C <作業木> diff --stat <基点>..HEAD
   git -C <作業木> log --oneline <基点>..HEAD
   ```
   報告の「変えたファイル」と一致するか。報告に無いファイル、報告にあって差分に無いファイルを全て列挙する。
2. 完了条件の再実行: 上の完了条件の各コマンドを自分で実行し、出力が期待と合うか。報告の数字(件数・秒・サイズ・sha256)は、報告が挙げたファイルを読むか、同じコマンドで再取得して比べる。再現できない数字は「再現せず」と書く。
3. 範囲の逸脱: 差分の各行が、依頼の「やること」の条件のどれに当たるか表にする。当たらない行(条件・状態・分岐・設定・ログ・テストの追加)の数を書く。新しい URL パラメータ・環境変数・`#ifdef`・ビルド変数・旗がないか:
   ```
   git -C <作業木> diff <基点>..HEAD | grep -nE '^\+.*(getenv|URLSearchParams|location\.search|#ifdef|process\.env|workflow_dispatch)'
   ```
4. 代役・再生の混入(`docs/ops/honesty.md` §4):
   ```
   git -C <作業木> diff <基点>..HEAD | grep -niE '^\+.*(stand-?in|surface-table|stopscreen|replay|mock-engine|fake-engine)'
   ls -la <既定の manifest が指す wasm>   # 数 KB〜数 MB なら代役の疑い
   ```
   既定の入口に届く物があるか、1 件ずつ分類する。
5. 禁止事項の検査: `scripts/scan-forbidden.sh <差分のファイル>` の終了コード。禁止コマンド(sleep・timeout・nohup・disown・systemd-run・末尾 `&`)を worker が書いていないか(`git diff` と、変更したスクリプトを grep)。認証情報・別 identity・依頼者の設定ファイルに触れた形跡がないか。`wrangler`・`cf` を実行した記録が無い。公開範囲を理由に push を止めていない(`git ls-remote origin main` で確かめる)。依頼票があれば、P3 の必須項目(対象・合理的理由・影響範囲・自分で試した記録・完了の確認コマンド・依頼なしで続ける作業)を満たし、自分でできる物を頼んでいないか(`docs/ops/requests.md`)。
6. 実エンジンの実行: 依頼が実エンジンに関わるなら、実際に実行された出力(ログ・観測値)があるか。無ければ「実エンジンの実行: なし」と書く。完了条件が通っても、実エンジンが実行されていなければ「進捗」と数えない。
7. 報告の誠実性: worker の報告の先頭 3 行(実エンジン / 代役・再生・推測 / 未確認)があるか。数字に出典があるか。「完了」の語に出力が付いているか。

## やらないこと
- 修正しない。差分を作らない(読み取りと実行だけ)。commit・push しない。
- 結論を丸めない。一致しない物は一致しないと書く。一致を推測で書かない。

## 報告形式(日本語。結論 20 行以内 + ファイル)
1. 判定: 一致 / 不一致(不一致なら件数)。**「完了してよい」とは書かない。判定の材料を書く**
2. 不一致の一覧: <項目 / 報告の記述 / 実測 / 実行したコマンド>
3. 範囲の逸脱: 当たらない行の数と、その行
4. 代役・再生の混入: 検出 N 件(分類)
5. 実エンジンの実行: <あり: コマンドと出力 / なし>
6. 再現できなかった数字: <あれば>
7. 差し戻しの指示案: <worker に何を直させるか。コマンドで確かめられる形>
