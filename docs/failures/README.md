# 失態の記録

メインセッション・後任・サブエージェントの失態を、1 件 1 ファイルで事細かに残す。依頼者が指摘したその日のうちに、指摘した本人(エージェント)が書く。`ops/lessons.md` は前任の 1 ページの要約で、ここは 1 件ずつの詳細。

- 書くのは事実だけ。出典(依頼者の発言 ID、コマンド、コミット、実行 ID、ファイルの行)を付ける。確かめていない物は「未確認」。
- 原因は、その時の判断で書く。「仕組みのせい」「圧縮のせい」「道具が止めた」と外的要因に見せる書き方をしない(制限を作ったのは自分)。
- 指摘された 1 件で終えない。同じ型を全部探し、探した範囲・コマンド・件数を、各記録の「同じ型の探索」に書く。
- 雛形は `TEMPLATE.md`。番号は続き番号。一覧は下の表に 1 行足す。
