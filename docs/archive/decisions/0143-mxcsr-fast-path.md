## ガードの定義(実装は `fle_mxcsr_flags.h` の「fast path」の節)

1 レーンが高速経路に入る条件(すべて):

1. ゲストの MXCSR の **RC(14:13)= 0**(最近接偶数)。`FLE_MX_FAST_CTL`(既定 0x6000)。マスクビット(7〜12)は見ない(旗が立っても `fle_mx_fin` がマスク解除を従来どおり扱う)。
2. オペランドが**ゼロか正規数**(NaN・Inf・非正規は従来経路)。窓: add/sub は指数部 1〜0x7fd(|x| < 2^1023)、mul/div/sqrt は正規数すべて(1〜0x7fe)、除数は非ゼロ、sqrt のオペランドは負でない(±0 はそのまま返す)、cvtsd2ss は |x| が 2^-126 以上 2^128 未満、f2i は |x| < 2^31(切り捨て)/ 2^31−1(丸め)/ 2^51(64 ビット)。
3. 結果が**正規数で最小の正規数より大きい**(`res64`/`res32`)か、正確なゼロ(オペランドのゼロ、または x + (−x))。オーバーフロー・アンダーフロー・非正規の結果・最小の正規数ちょうどは従来経路。
4. コンパイラが `FLT_EVAL_METHOD == 0`、`-ffast-math` なし、(clang でなければ)FMA 融合なし。clang では各関数の先頭に `#pragma clang fp contract(off)`。条件に合わないコンパイラでは高速経路は**コンパイルされない**。`-DFLE_MX_NOFAST` でも消せる。

この条件のとき、IE(NaN・Inf・無効演算)、DE(非正規オペランド)、ZE(ゼロ除数)、OE、UE(アンダーフロー結果)は**起こり得ない**。DAZ は非正規オペランド、FTZ は tiny な結果にだけ効くので、**FTZ・DAZ の値は結果にも旗にも影響しない**(差分テストで FTZ・DAZ の全組み合わせを混ぜて確認。ガードを 0xE040 にした構成も同じ結果)。**PE だけ**を厳密に判定する。

## PE の判定(導出)

- **add / sub(double)**: `s = a + b`(ホスト)、Knuth の TwoSum の誤差項 `err = (a − (s − v)) + (b − v)`, `v = s − a`。`a + b == s + err` は厳密(丸めが最近接偶数で、中間がオーバーフローしないとき。窓 |x| < 2^1023 で保証)。**PE ⇔ err ≠ 0**。
- **mul(double)**: `p = a * b`(ホスト)。有効桁(隠れビットを含む 53 ビット)`ma, mb` の厳密な積 `P = ma·mb`(106 ビット)の下位 52 ビット(P < 2^105 のとき)または 53 ビット(P ≥ 2^105 のとき)が捨てられる。**PE ⇔ 捨てられるビットが 0 でない**。それは P の下位 64 ビット(`ma * mb` の 64 ビット乗算)に全部入る。どちらの場合かは `p` の指数部と(オペランドの指数部の和 − 偏り)の差 c(0 か 1)で決まる。丸めの繰り上がり(P < 2^105 が 2^105 に丸められる)は P の下位 52 ビットが非 0 なので 53 ビットの検査でも PE になり、**曖昧な結果は無い**。c が 0 でも 1 でもないときは従来経路。**PM の提案の Dekker/Veltkamp の TwoProduct は使っていない**(S-fp1-intpe)。
- **div(double)**: `q = a / b`(ホスト)。**PE ⇔ q·b ≠ a**。`a = ma·2^(Ea−1075)` などとすると q·b == a は `mq·mb == ma·2^s`、`s = 1075 + Ea − Eb − Eq`(E は指数部)。正しく丸めた q の相対誤差は 2^-53 以下なので差 D = mq·mb − ma·2^s は |D| < 2^s、s ≤ 62 なら 2^63 未満で、**下位 64 ビットが等しければ D = 0**。s > 62 は従来経路。
- **sqrt(double)**: 同じ形。`s = 1075 + Ea − 2·Eq`、q² の相対誤差は 2^-52 以下で |D| < 2^(s+1)、s ≤ 61。
- **float(binary32)の add sub mul div sqrt**: double で計算し `(float)` に丸める。double は 53 ≥ 2·24 + 2 ビットなので、二重丸めは + − × ÷ √ で無害(Figueroa 1995、Boldo–Daumas 2003 — **読んだのではなく記憶による出典。確認していない**)。PE: add/sub は TwoSum の誤差が非 0 か、`(double)f ≠ d`。mul は `(double)f ≠ d`(float 同士の積は double で厳密)。div は `(double)f · y ≠ x`(24 + 24 ビットで厳密)。sqrt は `t·t ≠ x`。結果が float の正規数で最小の正規数より大きい(または正確なゼロ)ときだけ採用。
- **変換**: cvtss2sd は厳密(旗なし)。cvtsd2ss は `(double)f ≠ d`。cvtsi2sd32 は厳密。cvtsi2sd64・cvtsi2ss は丸めて、PE は整数で比べる(64 ビットで結果が 2^63 になる場合は PE)。f2i は切り捨て `(int64)x` と、丸めは `(|x| + 2^52) − 2^52`(最近接偶数)、PE は `t ≠ x`。
- **comi / min / max**: ゼロ・正規数・Inf(NaN・非正規は除く)のとき旗は立たず、ホストの比較が厳密。ZF = (a == b)、CF = (a < b)、PF = 0。
- **PE がすでに立っていてマスクされているとき(S-fp1-sticky)**: PE は sticky なので、MXCSR に PE が立ち、かつ PM(bit 12)が立っていれば、PE を判定しなくても MXCSR の最終値は同じ。判定を省く(`FLE_MXF_NP`)。PM が立っていないときは必ず判定する(立つと停止するため)。エンジンは 0x9fe0(PE が立ち、PM もマスク)でほとんど走る。

packed 命令(addps など)は各レーンで同じ関数を使い、旗は全レーンの OR のまま(1 命令 1 回の旗更新)。

## 差分テストの設計(`lift/harness/fp1/`)

`mxfp_diff.c`: 4 つの実装を 1 つのプログラムにリンクして、同じ入力を与える。**new**(高速経路つきの runtime)、**nofast**(同じヘッダを `-DFLE_MX_NOFAST` でコンパイル)、**old**(HEAD ac5a790 のヘッダを**そのまま**コピーした `ref/fle_mxcsr_flags_old.h` = 基準)、**host**(命令そのものをホスト CPU で実行する `crates/fe-lift/tests/ref/fle_mxcsr_flags_host.h`、x86-64 のみ)。比べるもの: 結果の XMM(16 バイト)、汎用レジスタ、MXCSR の全ビット、COMIS の旗 6 つ。new と old が基準、nofast と old は『整数経路が変わっていない』、new と host は『実機と同じ』。
