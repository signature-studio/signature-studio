## 決定

### A9 user32（`fle_user_nowin.c`）

1. **大文字小文字の変換は ASCII だけ**。`fle_env.h` の `fle_w_fold` と同じ方針。0x80 以上の UTF-16 単位が変換対象に含まれたら `fle_stop`（名前付きの abort）。理由: ページは ASCII 外の対応表を書かない。ページが書く「i と I は言語にかかわらず同じ対応」（トルコ語の注意書き）は ASCII に限って適用できる。
2. **CharLowerW / CharUpperW**: 引数の上位 48 ビットが 0（0x10000 未満）なら 1 文字で、変換した文字を返す。それ以外は文字列で、その場で変換してポインタを返す。「ワードの上位が 0」の 64 ビットでの読み（0x10000 未満）は**推測**。成功・失敗の指標も最終エラーもない（ページ）。
3. **CharLowerBuffW / CharUpperBuffW**: `cchLength` 個を NUL を含めて変換し、`cchLength` を返す（ページ）。`cchLength` は DWORD（rdx の下位 32 ビット）。0 のときは何も調べず 0（推測）。NULL バッファと正の長さは止める。
4. **CharNextW**: 次の文字へのポインタ。NUL を指すときはそのまま返す（ページ）。ページは「a + 結合文字は 1 文字」と書く。p[0] が ASCII で p[1] が NUL または ASCII のときだけ応答する（+2 バイト）。p[0] が 0x80 以上、p[1] が 0x80 以上（結合文字・サロゲートの可能性）、CR LF（1 文字か 2 文字かをページが書かない）は止める。
5. **RECT 4 件**: 公式で決まる（RECT は LONG 4 つ）。空の矩形は IsRectEmpty の定義（right <= left または bottom <= top）。
   - SetRect: 4 つのメンバを代入、1 を返す。NULL は止める。
   - IntersectRect: 交差を dst に書き、交差があれば 1。交差がなければ**全座標 0 の矩形**を書いて 0（ページ）。dst は NULL 不可（ページ）。src を先に読んでから dst を書く（閉包は dst = src1）。
   - UnionRect: 両方を含む最小の矩形。「空の矩形の寸法は無視する」（ページ）。片方が空のときは他方。結果が空でなければ 1。**両方が空のときは dst に何を書くかをページが書かない**ので止める。
   - OffsetRect: dx、dy の分だけ移動、1 を返す。ページは失敗の場合も 32 ビットの桁あふれも書かないので、桁あふれと NULL は止める。
6. **RegisterWindowMessageW / RegisterClipboardFormatW**: 値の範囲は 0xC000〜0xFFFF（ページ）。**値の割り当て順（0xC000 から 1 ずつ）は環境の設定で、ページにはない**。同じ名前は同じ値（ページ）。クリップボード形式の名前の比較は大文字小文字を区別しない（ページ）。ウィンドウメッセージの名前は「同じ文字列」としか書かれず、大文字小文字だけが違う名前の扱いは決まらないので止める。メッセージとクリップボード形式は別々の名前表を持つが、値は 1 つの数え上げから出す（同じ値を共有しない。この共有しない選択も環境の設定）。名前が NULL、空、0x80 以上を含む、255 単位を超える（実装の上限）ときは止める。0xC000〜0xFFFF（16384 個）を使い切ったときは、エラー番号をページが書かないので止める。
7. **GetClipboardFormatNameW**: 登録済みのクリップボード形式の名前をコピーして長さを返す（ページ）。存在しない値と定義済み形式（CF_TEXT など）は 0 を返し、最終エラーを 87（ERROR_INVALID_PARAMETER）にする。**エラー番号は実行環境の選択（仮定）**。ページは「要求した形式が存在しないか、定義済み」としか書かない。名前が長いときの切り詰めはページに書かれているが、`cchMaxCount` が NUL を数えるかが書かれていないので、「長さ + 1 が `cchMaxCount` 以内」の場合だけ応答し、それ以外は止める。メッセージとして登録された値は、クリップボード形式として見えるかがページにないので止める。

### A10 winmm（`fle_winmm.c`）

1. **MIDI デバイスは 0 台**。midiInGetNumDevs、midiOutGetNumDevs は 0 を返す（ページ: 「0 はデバイスがないことを示し、エラーではない」）。**「0 台」は環境の設定で、実機の値ではない**。オーディオ・MIDI の出力の実体はない。
2. **midiInGetDevCapsW / midiOutGetDevCapsW**: デバイスがないので識別子はすべて範囲外で MMSYSERR_BADDEVICEID（ページ: 「識別子が範囲外」）。バッファは触らない。ページは複数の誤りが重なるときの優先順位を書かないので、ポインタが NULL のとき、サイズが 0 のとき（ページは 0 なら NOERROR でコピーしないと書くが、範囲外との優先順位が不明）、識別子が 32 ビットを超えるとき（デバイスハンドルかもしれない）は止める。**midiOutGetDevCapsW の MIDI_MAPPER（(UINT)-1、符号拡張も含む）は止める**: ページは MIDI_MAPPER を有効な識別子とするが、デバイスがないときの戻り値を書かない。**閉包の列挙ループ（0xba4648、0xba47fc）は台数 0 のとき、まさにこの MIDI_MAPPER で最初に呼ぶ形に読める**（上の表。読んだだけ）。実機の戻り値を作ってしまうよりも止めることを選んだ。この箇所に届いた時点で、MIDI_MAPPER の応答は未決。
3. **midiOutGetErrorTextW**: `cchText` が 0 なら何もコピーせず NOERROR（ページ）。エラー文字列はシステムの文字列でページに書かれておらず、MMSYSERR_BADERRNUM の範囲も書かれていないので、それ以外は止める。
4. **midiOutOpen**: ページが挙げる 5 種のコールバック種別（NULL、WINDOW、THREAD、FUNCTION、EVENT）以外のフラグ、phmo が NULL のときは止める。mapper（(UINT)-1）を開くと MIDIERR_NODEVICE（ページ: 「MIDI ポートが見つからない。mapper を開いたときだけ」）、それ以外は MMSYSERR_BADDEVICEID。ハンドルは書かない。
5. **midiOutShortMsg**: ハンドルは作られないので、すべて MMSYSERR_INVALHANDLE（ページ）。
6. **timeBeginPeriod / timeEndPeriod**: 範囲内なら TIMERR_NOERROR、範囲外なら TIMERR_NOCANDO（ページ）。範囲は timeGetDevCaps が報告する範囲と同じ（推測。ページは範囲を定義しない）。ページ「呼び出しは同じ値の timeEndPeriod と組にする。複数回の timeBeginPeriod も、それぞれが組なら可」に従い、値ごとに回数を数える（最大 32 種の値。実装の上限）。組のない timeEndPeriod は戻り値をページが書かないので止める。**これらは仮想時計（`fle_sys.c`、決定 0017）を動かさず、時刻の応答も変えない**。仮想時計に分解能の概念はなく、Sleep(ms) はちょうど ms を加えるので、要求した分解能がゲストから観測できる差を作らない（テストで、これらの呼び出しの前後で `fle_sys_clock_ticks` が同じであること、Sleep が正確に ms を足すこと、timeGetTime が Sleep の分だけ進むことを確認した）。
7. **timeGetDevCaps**: TIMECAPS（UINT 2 つ、8 バイト）に wPeriodMin = 1、wPeriodMax = 1000000 を書き、TIMERR_NOERROR。ptc が NULL なら TIMERR_NOCANDO（ページ）。サイズが 8 以外のときは、無効なサイズの範囲をページが書かないので止める。**最小 1 ms は、仮想時計がミリ秒単位だから選んだ環境の設定。最大 1000000 は、実機で報告されることの多い値として記憶していたもの（非公式、確認していない。ページは値を書かない）**。環境の設定であって実機の値ではない。
8. **timeGetTime** は既存の `fle_sys.c`（決定 0017）のまま（仮想時計と整合している。変更していない）。

## 実装しなかったもの（この決定の対象外）

- 一覧の 22 API はすべて応答を実装した。実装していない API は 0。ただし上の各 API で「止める」と書いた入力は、応答の値を作らず `fle_stop` にしている（すべてページが決めない入力）。
- MIDI の実体（デバイス列挙、出力）、waveOut*、オーディオ出力: この M1 の範囲外。
- A9 の一覧にない user32 の API（GetSystemMetrics ほか D4、窓・メッセージ・GDI の D1〜D3）: 対象外。

## 確認できなかったこと（実装せず、止めるか、環境の設定とした）

1. ASCII 外の大文字小文字の対応（CharXxxW）。Windows のロケール依存で、ページに表がない。
2. CharNextW の結合文字・サロゲート・CR LF の扱いの全体（ページは結合文字の例だけを書く）。
3. RegisterWindowMessageW の名前の大文字小文字の扱い。
4. 0xC000〜0xFFFF を使い切ったときのエラー番号、GetClipboardFormatNameW の失敗時の最終エラー番号。
5. midiOutGetDevCapsW の MIDI_MAPPER とデバイス 0 台の組の戻り値（閉包の列挙ループが最初に呼ぶ形に読める。上記）。
6. timeGetDevCaps の最大値、無効なサイズの範囲、組のない timeEndPeriod の戻り値。
7. midiInGetDevCapsW の閉包内のサイズ引数 0x4c と MIDIINCAPSW の大きさの対応（台数 0 で届かない読みのため実害はないが、未確認）。

## 代替案

- MIDI_MAPPER に MMSYSERR_NODRIVER などの実機らしい値を返す案: デバイスがない機械の戻り値を書いたページがないので、推測の値を成功に近い形で隠すことになる。却下（止める）。
- メッセージとクリップボード形式で名前表を共有する案: 実機の挙動はページになく、共有すると値が衝突しうる。共有しない（環境の設定）。
- CharXxxW の ASCII 外を、ホストの `towupper` で変換する案: ホストの実物を見せることになり、ロケール依存で決定性が崩れる。却下。

## 限界

- 照合はページと、テスト内の独立のモデル（矩形の演算、ASCII の表、4000 組の矩形の格子）だけ。Windows 実機との比較はしていない。
- 閉包の呼び出し箇所の読みは逆アセンブルだけで、実行では確認していない。
- 数値定数（MMSYSERR_* など）は非公式の 2 つの源の一致による。
