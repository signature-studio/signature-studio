## 1. 方法

- **計器**: ページの `LatencyTracker`(決定 0141/0170/0202/0205/0223)の記録。1 入力ごとに、すべて同じ時計(`performance.timeOrigin + performance.now()`)で `tEvent`(ブラウザがイベントを作った時刻)、`tListener`(ページのリスナーの開始)、`tPage`(ページが送った時刻)、`tInject`(Worker がエンジンに渡した時刻。エンジンが idle のとき = Worker のイベントループがそのメッセージ/リングに届いた時刻)、`tIdle`(エンジンが処理して idle に戻った時刻)、`frames[desktop]`(その入力の結果として Worker が画を提示し終えた時刻 = 決定 0223 の `answer`。画素が変わらない入力には付かない)、`answers[].raf`(その提示のあとの最初の rAF の開始)。`latDump` が最後の 400 件を JSON で書き出す。**新しい計器は足していない**(`sdriveg2.mjs` に読み出しの 1 操作を足しただけ)。
- **区間**(`tools/lat-summary.py`。合計は厳密に **T = B + C + D**):
  - **A** = `tListener − tEvent`: ブラウザがイベントを作ってからページのリスナーが始まるまで(メインスレッドの待ち)。
  - **B** = `tInject − tPage`: ページが送ってから、エンジンに渡るまで。= リングに書く + (エンジンが idle〔parked〕なら)Worker への `wake` の `postMessage` + Worker のイベントループの待ち + (エンジンが idle でなければ)**次の idle まで待つ**。
  - **C** = `tIdle − tInject`: エンジンが渡された入力を処理して idle に戻るまで(FL の処理 + 協調スケジューラの待ち)。
  - **D** = `frame − tIdle`: idle から、答えの画の提示が終わるまで(`fle_desk_scene` の compose + `texSubImage2D` + draw)。
  - **T** = `frame − tPage`(ページが送ってから提示完了まで)、**TE** = `frame − tEvent`、**R** = `raf − tEvent`(ブラウザのイベントから、その提示のあとの最初の rAF まで = 画面に出せる最も早い時刻の近似)。
- **場面**(`tools/scn-lat.json`): (a) 起動直後、project を開く前の idle のメイン画面で `menuCycles`(File のボタンを押す〔60 ms hover、50 ms hold〕→ メニューの窓が見えるまで待つ → Esc → 窓が消えるまで待つ → 150 ms)×35。(c) Mixer のヘッダー(x 715→1015、y 564)を 40 ステップ × 60 ms で押したまま往復(80 回の移動。`drag` 操作)。(d) 参照プロジェクト `serina1-serum2.flp` を開き(Problems の窓を閉じる)、Space を 1.5 s おきに 32 回(奇数番が再生開始、偶数番が停止)。(b) Space で再生を始め 10 s 待ってから、(a) と同じ File メニューの `menuCycles` ×35、最後に Space で止める。
- **負荷**: 各 run の始めと終わりの `loadavg`(1 分)と、各区間の終わりの値(`tables/lat-*.md` の最後の列)を記録した。run 全体(約 9 分): r60 = 23.5 → 34.3、r120 = 31.1 → 32.3、r60b = 36.7 → 26.8。区間ごとの値は a = 18〜42、c = 17〜35、d = 17〜32、b = 31〜34。= **他の担当と共有の VM で、再生中の書き込み率が 0.3 台のときの値**。
- **対象**: 本番の bundle(ff5ee429)+ HEAD 91cbd9b0 のページ。60 Hz は `http://127.0.0.1:4990/`(本番と同じ構成)、120 Hz は `?hz=120` を読む**測定用のコピー**(`srcRH`。`hz.ts` の `applyHz` が測定値の代わりに N を渡す。製品のコードではない。新しい旗は足していない)。
- **フィルタ**: 『答えのある入力』= `frames` が付いた入力(画素が変わった物)。表の T は答えのある入力だけ。File メニューのクリックは『押下』の記録、閉じるのは Esc の『押下』の記録を使う(『離した』は画が変わらず、答えの無い物が大半)。
