## 6. 段階 2(WarpPerspective、FilterBoxBorder)— 着手していない(読みだけ)。同一性が示せない関数は HLE にしない

読み(lift した C を読んだだけ。HLE は書いていない。`dt/lifted_344fcf0.c`、`lifted_27ad5f8.c`、`lifted_27acd60.c`):
