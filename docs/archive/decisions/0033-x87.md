## 状態モデル

- 物理レジスタ `fle_x87_r[8]`（`m` 64 bit、`se` 16 bit の 80 bit 像そのまま）、TOP は `fle_x87.sw` のビット 11-13、タグ語は `fle_x87.tw`。ST(i) は物理 `(TOP+i)&7`。
- タグ語はレジスタ書き込みごとに更新（00 valid、01 zero、10 special、11 empty）。ホストの FNSAVE のタグ語と一致する（テストで比較）。
- **MMX との関係（再確認）**: MMX は独立の `uint64_t MM[8]`（決定 0028）で、ST とエイリアスしない。SDM と食い違うのは「MMX が書いた値を x87 が読む」「x87 の値を MMX が読む」場合。静的確認（`out-x87/work/mix.py`、結果 `mix-static.txt`）: all-pdata の閉包で MMX の mm 命令を含む関数は 5 つ（0x63a660、0x660c40、0x660c80、0x6a7900、0x6a7990、計 56 命令。`.text` 全体の mm レジスタ命令は 183）、x87 の演算を含む関数は 73。**両方を含む関数はない**。5 つの MMX 関数の直接呼び出しによる到達範囲（下向き）に x87 関数はなく、直接呼び出し元の側にも x87 関数はない（上向きの到達集合 0 件）。ただし**間接呼び出し（表経由のディスパッチ）は辿っていない**ので、間接経路での混在は静的には否定できない。そのため実行時の防御を足した: MMX 命令は `fle_x87_mmx_active = 1`、EMMS で 0。x87 命令は、その状態でタグ語が 0xFFFF でなければ `fle: x87: x87 instruction while MMX state is live (no EMMS); MM and ST are not aliased` で abort する（x87 命令の前に EMMS 相当でタグが全 empty なら続行）。

## 精度制御・丸め制御

- RC（ビット 10-11）: 最近偶数、−∞、+∞、0 方向を全部実装。
- PC（ビット 8-9）: 加減乗除と sqrt の結果を 24/53/64 bit に丸める。PC=01（予約）はホストで 64 bit と同じ結果だった（`probe2.c`）ので 64 bit とした。
- **ホストの実測で決めたこと**（SDM は規定していない、または読み取れなかった点）:
  1. 結果の丸めは、PC の精度で指数無制限の 1 回丸めの後、tiny の結果は PC 精度の非正規化の格子（2^(emin−pbits+1)）に丸める。tiny の判定は丸め前の指数、ただし最小正規数の 1 つ下の指数で丸めて正規数に繰り上がるものは tiny としない（seed を変えた突合で見つかった事例）。
  2. 定数ロードは RC で変わる（`probe3-out.txt`）。fldl2t は上向きのみ +1 ulp、fldl2e/fldpi/fldlg2/fldln2 は下向きと 0 方向のみ −1 ulp。PC には依存しない。
  3. IE または ZE が立つ命令では DE を報告しない。NaN 結果の算術では、ロード時に変換した非正規化の DE も報告しない。非正規化の比較で DE を出すのは NaN がない場合のみ。
  4. f32/f64 メモリオペランドの SNaN は、算術・比較の NaN 規則（SDM Table 4-8）では「signaling のまま」扱い、ロード（fld）では quiet 化して IE を立てる。
  5. FSCALE は DE をトップで先に立てる。

## 例外とステータスワード

- マスク済みの例外は SDM の結果を出し、PE/UE/OE/ZE/DE/IE と C1（丸め上げ）、C0/C2/C3（比較、fxam）を設定する。
- **未マスク例外（#MF）はモデル化しない**: 未マスクの例外が起きる命令、および命令開始時にマスクされていない例外フラグが `sw` に残っている場合は `fle: x87: unmasked exception (#MF not modelled)` / `fle: x87: pending exception flag is unmasked (#MF not modelled)` で abort。スタックのオーバーフロー・アンダーフローも `fle: x87: stack overflow/underflow ...; stack faults are not modelled` で abort（SF は立てない）。
- FLEngine の制御ワード: `fldcw` は `.text` 全体（`objdump-text.txt`。閉包内に限った数ではない）に 48 箇所。そのうち 10 箇所は RIP 相対で、参照先 4 アドレス（0x13a5050、0x13e4d4c、0x13e4d4e、0x13e4d54）の PE `.data` の初期値は 0x033F、0x073F、0x0F3F、0x033F（最近偶数、−∞、0 方向、最近偶数）。すべて例外マスクは 0x3F（全マスク）。ただしこれは初期値で、実行中に書き換えられるかは確認していない。**残り 38 箇所（`[rdx]`、`[rdi]`、`[rbp]` など実行時のアドレス）の値は静的には確認できていない**。動的には、harness の実行がまだ x87 に到達していない（`x87-run.md`）ので未確認。未マスクの値が来た場合は上の abort になる。
- 命令の C1: スタック例外でない場合の C1 は丸め上げ（inexact のとき）。fist 系は inexact のときの丸め方向。
