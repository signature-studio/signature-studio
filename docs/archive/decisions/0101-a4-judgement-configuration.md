## 0046 と 0086 の関係（矛盾の明記）

**矛盾がある。** 文言の上で次の 2 つが両立しない読みを持つ。この決定は解消せず、どちらを採ったかと、解消されていない点を書く。

2. 決定 0073 の決定 5（22 行）: 「この決定は M2 の一部だが、A4 の完走に必要なものとして扱う（PM の方針）」。決定 0086 は、この方向を Blend2D と QFC に広げ（54〜57 行）、実在モジュールとして載せる順を「ブートの停止点の順」（58 行）とする。
3. **0086 は 0046 の方針 5 を扱っていない。** 0086 の本文に `0046`、`A4`、`M1` の語は無い（`grep` で確認）。「M2」は、0029 の「M2 の判断」を引いて、残りの名前の扱いは 0029 のままとする 143 行だけ。0086 の「関連する決定への影響」（137〜145 行）の一覧に 0046 は無い。

**この決定の扱い。**

- 決定 1 は、InitUnits の中で `LoadLibrary` される同梱 DLL を A4 の判定構成に入れる。これは 0073 決定 5 の側（A4 に必要）を採る。方針 5 を文字どおり読めば、これらの DLL の lift は M2 の作業で、M1 の A4 は単独構成の値（145 / 942。progress.md 93 行の「厳格な読み」）で測ることになる。単独構成は必ず止まる（背景）ので、その読みでは、M1 の完了条件に M2 の作業が入るか、A4 が M1 で達成できないかのどちらかになる。この決定は、その読みを採らない。
- 0046 の本文は書き換えない。方針 5 のうち、InitUnits の外で読まれる DLL、プラグイン、A4 の判定構成に入らない DLL の扱いは、この決定では何も決めない。**方針 5 の対象をどう読み替えるか（または 0046 に注記を足すか）は未決**。
- 決定 1 は、0046 の A4 の判定基準（完走の条件）を変えず、判定する構成を選ぶ解釈である。ただし、単独構成は 0073 を保つ限り必ず止まる（背景）ので、構成の選択が、A4 が達成できる条件かどうかを分ける。「判定基準を変えない」という整理が成り立つかは、PM が確認する点として残す。
