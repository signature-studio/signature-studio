# 決定 0268(仮): ページがエンジンに渡す表示 Hz の上端を 120 にする

状態: **仮の決定**。作業者 `gpu1`(成果物名は gpu6)、2026-11-06 JST 00:05〜。基準 HEAD: **1c78f3c5**(差分は `git archive` した同 HEAD の 2 ファイルに `patch -p1 --dry-run` が通る)。依頼者の機械・実ディスプレイの値は 0 件。

## 変更

`app/src/engine/hz.ts` の `STANDARD_HZ` を `[60, 75, 90, 120, 144, 165, 240]` から **`[60, 75, 90, 120]`** にする。測定した rAF の中央値が 120 を超える画面(144 / 165 / 240 / 360 Hz …)は、これまでの 144 / 165 / 240 でなく **120** を `FLE_DWM_HZ` と `FLE_DISPLAYSETTINGS_FREQUENCY` に渡す。1 箇所の定数で、旗・URL パラメータ・環境変数・ビルド変数は足していない。`roundToStandardHz` の規則(比の意味で最も近い標準の値、両端はその値)は変わらず、上端が 240 から 120 になっただけ。ファイル先頭のコメント、`S-hz-standard` の注釈、`S-hz-round` の注釈を実装に合わせた。`test/unit/hz.test.ts` を同時に直した(標準の一覧、丸めの表、`measureFrameRate` の 144 / 240 Hz の行、±15% の揺れの試験、`applyHz` の例。新しい試験: 『どの測定値も 120 を超えず、120 を超える測定値はちょうど 120』)。ほかに 144 / 165 / 240 の渡し値を期待している試験は無い(`grep` 済み。`perf-display.test.ts` の 144 / 240 は画面側の計測器と `hzClass` の分類で、エンジンに渡す値ではない)。

## 根拠(決定 0263 §10 の表。この機械、headless Chrome 156、実 GPU なし、各 1 回)

エンジンに渡す Hz を変えたときの、Song Mode 再生 45 s(scene b)の書き込み率(0–45 s / 10–45 s)と、UI・ミキサーの CPU(ms/s):

| 渡した Hz | 書き込み率 | UI | ミキサー | idle(開いて止めたまま)の UI / Worker busy |
|---|---|---|---|---|
| 60 | 0.363 / 0.287 | 380 | 416 | 297 / 418 |
| 120 | 0.326 / 0.247 | 505 | 336 | 503 / 607 |
| 144 | 0.310 / 0.228 | 536 | 304 | 642 / 745 |
| 240 | 0.291 / 0.210 | 601 | 267 | 856 / 953 |

120 を超える Hz は、画面に出る絵を増やさず(FL のアニメは 120 tick/s が上限になる設計)、tick の仕事(idle で 1 tick 約 3 ms の Worker)だけが増えて、再生中は飽和した Worker の中でミキサーの取り分を減らす(120 → 240 で書き込み率 −0.035 / −0.037。揺れは ±0.013)。60 → 120 の −0.037 は P2(120 fps)の代価で、これは受け入れる。

## 見え方の注意(コードと算術からの読み。実ディスプレイは未確認)

- 上端を 120 にすると FL のアニメ(再生位置の線、メーター、時計)は最大 120 回/秒の更新になる。提示は『画素が変わった rAF だけ』なので、144 Hz の画面では新しい絵が 120/s、**6 フレームに 1 回、同じ絵が 2 フレーム続く**(24 Hz の拍)。165 Hz では 1 tick が 1.375 フレームで、2 フレーム続く回数が 45 回/s の不規則な並び。一定速度の動き(再生位置の線)に、この拍のジャダーが見える。240 Hz は 1 tick = 2 フレームで均一(ジャダーなし)。120 Hz 以下の画面は変わらない。
- tick は仮想時計で、実 vsync と位相が固定されない。書き込み率が 1 未満の間は渡した Hz の何分の 1 しか回らない(いま 0.3 台)ので、**P3 を満たすまでは 120 でも 144 でも見え方は同じ**。ジャダーは P3 達成後の話。
- 画面側の計器(perf パネルの `hzFit`)は、144 Hz 以上の画面で『この画面は 144 Hz 相当ですが、エンジンは 120 Hz で描画しています』(`engine-slower`)を出す。意図した表示で、変更はしていない。
