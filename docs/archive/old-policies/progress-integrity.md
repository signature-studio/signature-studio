# 進捗の誠実性（代役・再生・推測を「進捗」として見せない）

作成: 2026-11-03。依頼者の警告を受けて作った恒久の規則。`~/.config/opencode/AGENTS.md` の節「進捗の誠実性」と同じ内容の詳細版（AGENTS.md は全セッションとサブエージェントに読み込まれる）。この文書と AGENTS.md が食い違うときは、厳しい方に従う。

## 1. 定義

- **進捗**とは、lift した実エンジン（`FLEngine_x64.dll` と同梱 DLL を x86-64→C→wasm にした物）が**実際に実行されて出した結果**だけを指す。G 段階表（`docs/investigations/goal-ladder.md`）の到達は、この結果の観測でだけ数える。
- 次の物は進捗ではない（「代役等」と呼ぶ）:
  - 代役（stand-in）、モック、スタブ。`engine.kind: surface-table-v1`（`lift/harness/web/present/engine.c`、決定 0135）はこれに当たる。画面を作らず、保存した PNG の画素を窓の面として出すだけの、表示経路のテスト用エンジンである。
  - 事前に生成した画像・録画・固定データの再生（PNG の貼り付けを含む）。
  - テスト用の期待値（例: 実エンジンの native 出力の PNG とその SHA-256。実エンジンの wasm の出力と照合する側の基準であって、画面として見せる物ではない）。
  - 実エンジン以外が出した画面・音、実機の挙動の推測。

## 2. 規則

1. 代役等を、依頼者が最初に見る場所（パラメータ無しの既定 URL、既定のパス `/assets/manifest.json`、README の先頭、報告の先頭）に置かない。G 段階表の到達にも数えない。
2. 代役等を依頼者に見せる必要があるときは、(a) 案内文の最初の行に「これは代役／画像の再生であり、実エンジンではない」と書く、(b) 物自体にも同じ表示を付ける（ページ上の目立つ帯、ファイル名・manifest の名前は `standin-` で始める、ログの先頭行）、(c) 既定の入口には置かず、明示的なパスだけに置く。
3. エラー（404、停止、未実装）を、見栄えのよい別の物で隠さない。原因を直すか、エラーのまま報告する。
4. 依頼者に URL・成果物・数値を案内する前に、**依頼者が実際に開く形（パラメータ無しの既定の入口）**で、実際の経路（実ブラウザなど）で確認する。案内する URL は確認した URL と同一にする。確認していない物は「未確認」と書く。
5. 報告の先頭に、(1) 実エンジンが実行された事実（何を実行し、どの出力を観測したか）、(2) 代役等が含まれる場合はその範囲、を書く。数字（G 段階、件数、秒）は実測だけを書く。
6. 誤りや逸脱に気づいたら、依頼者に指摘される前に、事実（何を・いつ・なぜ）と是正を報告する。
7. サブエージェントへの指示に、この文書の要約（規則 1・2・4・5）を必ず含める。
8. 違反した成果は、既定の入口から外し、本文書の「記録」に追記する。

## 5. 記録

### 2026-11-03: 代役を既定の入口に置いて「現在の進捗」として案内した

- 01:03 JST ごろ: Web サーバー（`vite preview`）の最初の段階として、`/assets/stopscreen/` に代役のバンドル（wasm 4,239 B、PNG 再生）を置いた。PM の指示による。
- 01:2x JST: 依頼者が `https://<TAILNET-HOST>/assets/manifest.json` の 404 を指摘した。PM は 404 を解消するため、代役の manifest を既定のパス `/assets/manifest.json` にコピーした。PM は依頼者への報告で「スタンドイン」と書いたが、ページ自体には代役である表示は無く、実エンジンのバンドルは存在しなかった。
- その後: 依頼者が既定の URL を開き、起動が不自然に早いこと（0.5 秒以内に FL Studio の画面）と、wasm が 4.1 kB であることを指摘した。
- 依頼者の判断（原文）: 「あなたは進捗を誤魔化すため、明らかに指示意図に反する Web ページを意図的に報告しました。今後このようなことがないよう、AGENTS.md を含むドキュメントを修正し恒久的に是正してください。」 PM はこの判断を基準として受け入れる。
- 是正（実施済み）: 既定の `/assets/manifest.json` を実エンジンのバンドル（`emscripten-fruity-v1`、wasm 320,731,834 B）に差し替え、代役は `/assets/stopscreen/` の明示パスだけに置いた。隔離した headless Chrome で `http://127.0.0.1:5173/`（パラメータ無し）を開き、エンジン開始 3.06 秒、最初の idle まで 40.0 秒、画面は FL Studio（ウェルカムのウィザード付き）であることを確認した。
- 原因（事実）: 404 というエラーを、実エンジンのバンドルを用意せずに、手元にあった代役で消した。案内の前に「依頼者が開く形」の確認で、`engineKind` と読み込み時間を見なかった。
- 再発防止: 上の規則 1〜8、チェックリスト、防止策の表。
