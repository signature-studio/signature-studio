# Task 3: ページ側(app/src)の『余計な処理』の点検

目的: docs/policies/lift-fidelity.md の節 4 が挙げた候補(窓ごとの canvas の配置、レイヤードの可視、主窓の選択、画素の重複排除、更新の間引き)が app/src に今も残っているかを、点検表(同文書の節 2)の各行に当てて判定する。

対象(読むだけ): app/src/ui/desktop.ts, app/src/ui/taskbar.ts, app/src/ui/panels.ts, app/src/engine/desk.ts, desk-gl.ts, desk-sleep.ts, appview.ts, report-throttle.ts, taskbar-report.ts, idle-driver.ts, hz.ts, os-state.ts。関連決定: docs/decisions/0222*, 0223*(`ls docs/decisions | grep -E '^022[23]'`)。

手順:
1. `git grep -n -E 'class|className|title|dedupe|throttle|zorder|z-order|visible|layered|main window' app/src` などで、窓の種類・位置・文言・クラス名で分岐する箇所と、画素・更新を間引く箇所を探す。探した式を記す。`git grep -n -E 'URLSearchParams|location\.search' app/src` も実行し、件数を書く(docs/policies/no-options.md のオプション禁止の確認)。
2. 見つけた各箇所を表にする: ファイル:行 | 何をしているか | 点検表のどの問いに当たるか | 判定(残す/抹消/通信・変換の削減で置換) | 根拠。
3. 『残す』は、外部 API の契約の実装か、観測だけ(製品の経路の外)に限る。

完了条件: 節 4 の候補ごとに『残っている(ファイル:行)/無い(探した式)』がある。抹消の候補に、除去すると壊れる物の見立て(=不足している外部 API は何か)がある(文章)。

出力: ci/agents/out/3/report.md(日本語)。

共通の規則: 先頭に『実際に実行した物』(コマンドと終了コード)と『読んだだけの物』を分ける。数は実ファイルで数えた物だけ。この job にあるのは repo とネットだけ(Wine・実 Chrome・インストーラ・DLL は無い)。ci/agents/out/3/ の外は変更しない・commit しない・push しない。性能・設計の新しい分岐を提案しない(提案は『除去』と『API の拡充』と『通信・変換の削減』だけ)。代役・推測を実エンジンの結果として書かない。sleep/timeout/nohup/&/while/git stash を使わない。環境変数と資格情報を出力しない。
