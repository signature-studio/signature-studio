# Task 11: ci/ の試験の実行と、deploy.yml の plan job との照合

目的: リポジトリだけで動く ci/ の試験を実行して結果を報告し、.github/workflows/deploy.yml の job `plan` の step『static checks of the CI scripts』が実行する物と、この task が実行した物の差を示す。

実行する物(この順で。それぞれ終了コードと所要秒を記録する):
1. `for f in ci/*.sh ci/lib/*.sh app/scripts/build-engine-bundle.sh; do bash -n "$f"; done`
2. `shellcheck -x -S warning ci/*.sh ci/lib/*.sh`(shellcheck が無ければ `command -v shellcheck` の出力と『実行せず』と書く。入れる場合は apt のコマンドと結果を書く)
3. `python3 -m py_compile ci/lib/*.py`
4. `bash ci/test-needs.sh`, `bash ci/test-hybrid.sh`, `bash ci/test-lifecycle.sh`, `bash ci/test-b2d-key.sh`, `bash ci/test-wrangler-config.sh`, `python3 ci/test-real-deploy.py`
5. deploy.yml の artifacts.lock の awk 検査(deploy.yml の該当 step の run をそのまま写して実行)

照合: deploy.yml の step の run を読み、上の 1〜5 に無い行があれば挙げる。ci/ に tests と名の付く物で deploy.yml が呼ばない物があれば挙げる(`ls ci` と `git grep -n 'ci/test-' .github` を使う)。

完了条件: 各コマンドの終了コード・所要秒・出力の末尾 3 行が表にある。失敗があれば出力全文。照合の結果(差が無ければ『差無し』)がある。

出力: ci/agents/out/11/report.md(日本語)。

共通の規則: 先頭に『実際に実行した物』(コマンドと終了コード)と『読んだだけの物』を分ける。数は実ファイルで数えた物だけ。この job にあるのは repo とネットだけ。ci/agents/out/11/ の外は変更しない・commit しない・push しない。試験を弱めて通さない。代役・推測を結果として書かない。sleep/timeout/nohup/&/while/git stash を使わない。環境変数と資格情報を出力しない。
