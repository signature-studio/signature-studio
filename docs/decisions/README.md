# 決定文書の書き方(docs/decisions/)

新しい処理・分岐・特別扱い・除去・測定に基づく判断は、決定文書を 1 本書く。旧決定は 0001〜0345(原文は `docs/archive/decisions/`)。
**新しい番号は 0346 から連番**(`ls docs/decisions` の最大番号 + 1。欠番・重複を作らない)。ファイル名 `NNNN-題(英小文字とハイフン).md`。

規則:
- 1 本 1 ページ・**100 行以内**。先頭 5 行以内に **分類** と **撤回条件**。分類は (a) 除去 / (b) API 拡充(外部 API の契約の実装) / (c) 通信・変換の削減 のどれか 1 つ。書けないなら足さない(`AGENTS.md` §6)。
- **実測**(コマンド・条件・日付つきの出力)と **読み**(コード・文書を読んだ解釈)を分けて書く。数字は実測だけ。区分の無い数字を書かない。
- 前後の測定(P1〜P3 の該当、n、マシン・ブラウザ)と、比べたコミットを書く。旗・環境変数・`#ifdef` で切り替えない(コミット同士で比べる)。
- 依頼者に判断を委ねない。「決定: X。根拠: Y」で閉じる。
- 新しい `#ifdef`・`getenv`・URL パラメータを足さない。既存を持ち込むときは 1 件ずつ「オプション(除去)/ 部品間パラメータ(残す)/ 試験専用」に分類して書く。

雛形:

```md
# NNNN: <題 1 行>
分類: (a 除去 / b API 拡充 / c 通信・変換の削減)
撤回条件: <何が起きたら・何を測ったら元に戻すか>
日付: YYYY-MM-DD   ROADMAP: <ID>   台帳: <L..>   コミット: <前>..<後>
## 決定
<1〜3 行。「決定: X。根拠: Y」>
## 実測(コマンド・条件・日付・n)
## 読み(解釈。実行していない)
## 未確認
## 出典(旧決定番号・ファイル)
```
