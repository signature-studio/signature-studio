## 決定
1. 決定: 製品は変えない。試作の計数(専用ブランチ `r4-5d-rt`、commit `d7668e24`・`da28537b`)は push しない。根拠: 計数は GIL の経路に追加を入れたもので、製品の挙動を変える。差分は `evidence/R4-5d/diag.patch`。
2. 決定: 計数の範囲では、rt の入力遅延の増分の主因を GIL の待ちとは見なさない。根拠: Worker 0 の GIL の待ちは、入力の engine 段の窓の中で平均 0.03〜0.10 ms(engine 段は約 30 ms)。他の Worker の長いスライスは窓に重ならない(`evidence/R4-5d.md` §3.3)。
3. 決定: a か b かは決めない。根拠: 増分の残り(engine +12〜19 ms、queue +5〜7 ms)の原因が未特定で、分類の前提が揃わない(`evidence/R4-5d.md` §5)。
4. 決定: Export の sha の差は、1 LSB の単独フレーム(連続 1 フレーム。最大 28 フレーム/組)として記録する。根拠: 既存の 12 本の WAV の比較(`evidence/R4-5d/wav-pairs.tsv`)。原因(どの Worker・どの plugin)は未特定。
