# G 段階(G0〜G11)

冒頭: (1) **実エンジンがこの機械で実行された記録は、まだ無い**(ROADMAP R0 の前)。下の判定は旧資料の自己判定で、**再測定していない**。 (2) 旧測定は前任の開発機・headless Chrome 156/Firefox 158・模擬入力。実機 Windows との照合は 0 件、依頼者機の値: 依頼中(Issue。未返答)。代役・再生が混ざった時期があった(`docs/ops/lessons.md`)。 (3) 未確認: 段階の到達は「実エンジンが実行して出した結果の観測」だけで数える(`docs/ops/honesty.md` §1)。**段階の数字を R0 の実測で書き換える**(STATE.md)。

## 1 定義(旧 `goal-ladder.md` §1。観測はブラウザ側で)

| 段階 | 名前 | ブラウザで観測できる受け入れ条件 |
|---|---|---|
| G0 | エンジン初期化の完走 | Worker 内の wasm で DllMain→InitUnits が 942/942 で完走し、a4 の 7 行が native と一致 |
| G1 | `CreateFruityInstance` が Run の入口に着く | Worker のログに Run(0x1375950)の入口への到達。署名検査・CPU 検査・初期化を通過 |
| G2 | メインウィンドウの作成 | 窓表に可視の最上位窓。サイズとタイトルが JS から読め、canvas と `document.title` に反映できる |
| G3 | メッセージループが回る | 待つ間もタブが応答し、`WM_TIMER` が等間隔で届く。アイドルで CPU を使い切らない |
| G4 | 最初の 1 フレーム | エンジンが描いた画素が canvas に出る(空白でない) |
| G5 | 完全な初期画面 | メニュー・ツールバー・ブラウザ・プレイリスト・ミキサーが文字・アイコンつきで描かれ、**実機のスクリーンショットと領域ごとに比較できる** |
| G6 | 入力の往復 | マウス・キー・ホイールが `WM_*` として届き画面が変わる |
| G7 | 音声デバイスと無音の出力 | AudioWorklet が一定のブロックを連続して受け取る(アンダーラン 0 を一定時間) |
| G8 | プロジェクトの読み込みと再生(内蔵音源のみ) | `.flp` を読み、再生で非ゼロのサンプルが出る。書き出しを実機と比較 |
| G9 | 同梱プラグイン | `Plugins\Fruity` の DLL(160 個)を読み、GUI が出て音が出る |
| G10 | UI の広範な操作・保存・書き出し | ピアノロール・ミキサー・設定・ダイアログ・保存・WAV/MP3 書き出し |
| G11 | 外部プラグイン・ライセンス・オンライン | VST2/VST3/CLAP の第三者プラグイン、ライセンス、更新確認 |

**P1〜P3 を G11 の到達条件に含める**(旧 `performance-targets.md` §5)。G6 は P2、G7 は P3 を満たすまで「達成」と数えない(**G7 以降は P2・P3 が未達のため数えない** [文書])。

## 3 二通りの読み(旧 0198・0314。ここでは判定に使わない)

旧資料は「最も厳しい読み = G0、字義どおりの読み = G4」と自己判定した。**この数字は再測定していない。報告の先頭・ROADMAP の根拠に使わない**。G1〜G3 は各 1 項目の記録の欠け(Run 入口・`document.title`・`WM_TIMER`)があり、連続性を要求すると G0 に落ちる [文書: 0198]。
