## 3 音声 48 ファイル(旧資料。`tables/audio_files.tsv`)

計 701.1 秒・ファイル 61.4 MB・デコード後 float32 約 246 MB。**mp3 4 本が 518.8 秒・183 MB(74%)**。形式(旧資料の表): WAV PCM 8/16/24 bit と IEEE float 32 bit が 42 本、WAV に包んだ Vorbis(タグ 0x674f)1(拡張子 wav の 43 本に含む)、MP3 4、Ogg Vorbis 1。サンプルの参照 48 個は作者の一時フォルダの絶対パス 1 つに集まる(その絶対パスに置けば避けられる、と旧資料は読む)。

## 4 要求(旧資料のリスク。未検証)

1. **サードパーティ VST3 20 インスタンスは計画のどこにも無い(G11)**。プラグインを供給しなければ、FL は警告を出して**そのプラグインを無視して読み込みを続ける**(旧資料の読み)。Serum 2 の音は出ない。P3 の前提になる(旧 `performance-targets.md` §3)。
2. **サンプルの読み込み(G8)**: mp3 は msacm32 の ACM で復号(ランタイムに `acmMetrics` の行のみ)。Vorbis は `oggio_x64.dll`(8 モジュールに含まれる)。zip の展開は `DelZip64.dll` 未 lift、またはアプリ側。
3. **実時間の計算量(P2/P3)**: 空のプロジェクトで既に native -O2 の再生は実時間の約 1/20 だった(決定 0144、当時)。このプロジェクトは 127 インサート・3,565 クリップ・46 プラグインを足す。**当時の実測は無い**。
4. 旧本番では、FLP は開けて再生できた(0229・0236)が、内蔵エフェクト 7 種 25 インスタンスと Fruity Wrapper は開けず、`8 plugin(s) could not be opened` と出た [文書]。Export の WAV は 22,863,828 B・sha256 `381cdb5a…f979` で完走(E13、旧記録)。Wine 上の原版とは MP3 復号器と CPUID を揃えた構成で 5,715,911 フレーム中 4 フレームが +1 LSB [文書]。

## 5 使い方

- P2/P3 の測定は、この zip を OPFS に置いて開く(旧検証キットの `proj` の手順。ROADMAP R4)。1 回の再生の長さ・位置(曲の重い区間を含む 60 秒以上)を測定記録に書く。旧記録は「60 秒の再生は音楽 40 秒前後まで。重い区間は未検証」と書く [文書]。
