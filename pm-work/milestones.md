## 説明(GitHub の description に入れる文)

### M1 描画と音声の分離(P3)

- 説明: 描画の合成と提示を、音声を作る Worker から分ける。分離の commit(43a6eb88)は main に在るが、本番には出ていない。分離の後の版で音声への圧迫が消えたかは、未実測。この Milestone は、分離の前後の実測、残る圧迫の解消、所定のプロジェクト(インストーラの demo)での P3 の実測を完了させる。
- 完了の条件:
  1. 分離の前後の版を同じ道具で、UI の負荷をかけて測り、音声の余裕の差が数字で報告されている(子 002)。
  2. UI の負荷をかけても underrun が 0 件(n=3)(子 040)。
  3. 所定のプロジェクト(インストーラの demo。子 004 で選ぶ)を Song Mode で再生し、underrun が 0 件(n=3)。

### M2 HiDPI と P2 の測定(P2)

- 説明: guest の画面を物理画素(CSS × 拡大率)にして、画面がぼやけないようにする。P2(UI の 120 fps)を測る道具を作り、HiDPI と描画の分離の後の値を測る。
- 完了の条件:
  1. 拡大率 1・1.5・2 で、canvas の幅と高さが CSS の大きさ × 拡大率(±1 画素)に一致する。
  2. guest に DPI(96 × 拡大率)が伝わる(設計の結果を報告に書く)。
  3. P2 の測定の道具が、フレーム間隔と入力の遅延を JSON で出し、120 fps の判定を「受理」「差し戻し」「未確認」のいずれかで書ける。

### M3 トップバーのコンテキストメニュー(P2)

- 説明: Tempo・Song Position・Pattern Selector の右クリックでメニューが画面に出て、項目を選ぶと engine に届き、部品の値が変わる。
- 完了の条件:
  1. 右クリックで、メニューが画面に出る(前後の画面の差が、クリック位置の近くに出る)。
  2. 項目を選ぶと、engine が WM_COMMAND を受け取る(engine のログに出る)。
  3. 3 つの部品それぞれで、メニューの項目を選んで値が変わったことを実測する。

### M4 FL に必要な物の配布

- 説明: FL Studio が必要とする物(インストーラ全件の一覧、FLEngine、言語パック、テーマ、プロジェクトテンプレート)を揃え、起動前に取る物と、起動後にバックグラウンドで取る物に分ける。最初の 1 件は Fruity Balance。
- 完了の条件:
  1. インストーラ全件の一覧が main にあり、件数と SHA-256 の検査が通る。
  2. 起動前に取る物と、起動後に取る物の区分が実装され、Fruity Balance が起動後に届く。
  3. 起動時に見つからなかったファイルが 0 件(記録の仕組みで確かめる)。
  4. 言語・テーマ・テンプレートが、一覧と件数が一致する。

### M5 内蔵のエフェクトとインストゥルメント

- 説明: 内蔵のエフェクト(Plugins の Effects 約 90 件)とインストゥルメント(Generators 約 51 件)を、1 プラグイン 1 wasm で起動後に届ける。数えるのは DLL のファイル数。件数は依頼者の申告で、インストーラの一覧で確かめる。OpenGL を使う VFX 系は、全群の後に入れる(子 039)。
- 完了の条件:
  1. OpenGL を使う VFX 系を除く全件が、起動確認(engine-idle・standIn が false・error が null)を通る。
  2. 全件が、起動後の取得で届く。
  3. 種類ごとに 1 件以上が、UI から選べる(M3 の後)。
  4. VFX 系(OpenGL)の全件が、子 039 で、全群の後に 1 プラグイン 1 wasm で入る。

### M6 外部プラグイン

- 説明: Serum 2・OTT・Vital の 3 件を、既定の経路(オプトイン無し)で読み込み、1 ブロックの音声を処理する。3 件のインストーラは R2 に既に在り、FL のインストーラと同じ経路で取る。
- 完了の条件:
  1. 3 件が既定で読み込まれ、1 ブロックの音声を処理する(実測)。
  2. VST3 の link が既定で有効になっている(オプトインが無い)。

### M7 エンジンの性能(P3 のホットパス)

- 説明: P3 の再生中に実行される命令の内訳を実測し、直接 wasm でない関数のうち命令数が多いものを、一括で直接 wasm にする。1 関数 1 タスクには戻さない。
- 完了の条件: P3 の再生中の命令数のうち、直接 wasm でない関数が 1% 以下(直接 wasm の割合が 99% 以上)。基準は子 031 で測る。

### M8 起動 10 秒以内とサイズ(P1)

- 説明: 起動(ページを開いてから engine-idle まで)を、runner で 10 秒以内にする。サイズの方針は、engine wasm の大きさの目標は無いこと、単一の wasm ファイルは、ブラウザが読み込める約 1GB 以下にすること。超える場合は分割する。起動前に取る量は、P1 の実測で決める。
- 完了の条件:
  1. 起動の中央値(n=3)が 10 秒以内。
  2. 単一の wasm ファイルが 1GB 以下(分割が必要な物は分割されている)。

### M9 完成の検証

- 説明: 6 課題と P1・P2・P3 の最終の実測を、同じ道具で行う。
- 完了の条件: C-1〜C-6 が全て「受理」になり、P1・P2・P3 の最終の実測が報告に出ている。判定は「受理」「差し戻し」「未確認」のいずれか。「達成」とは書かない。
