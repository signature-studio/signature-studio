## 説明(GitHub の description に入れる文)

### M1 描画と音声の分離(P3)

- 説明: 描画の合成と提示を、engine と音声の書き込みを行う Worker から分ける。実装は main に入っている(commit 43a6eb88)。この Milestone は、その受理と、所定のプロジェクトでの P3 の実測を完了させる。
- 完了の条件:
  1. 描画の Worker が canvas を持ち、描画の Worker の名前が実測で出る(受け入れの道具の出力)。
  2. 起動後の描画の合成の回数が、画面が動かない間は増えない(基準: 変更前の 36〜48 回/秒に対して 9 回/秒以下)。
  3. 所定のプロジェクトを Song Mode で再生し、underrun が 0 件(n=3)。入力は依頼者が用意する(QUESTIONS 1)。

### M2 HiDPI と P2 の測定(P2)

- 説明: guest の画面を物理画素(CSS × 拡大率)にして、画面がぼやけないようにする。P2(UI の 120 fps)を測る道具を作り、HiDPI と描画の分離の後の値を測る。
- 完了の条件:
  1. 拡大率 1・1.5・2 で、canvas の幅と高さが CSS の大きさ × 拡大率(±1 画素)に一致する。
  2. guest に DPI(96 × 拡大率)が伝わる(設計の結果を報告に書く)。
  3. P2 の測定の道具が、フレーム間隔と入力の遅延を JSON で出し、120 fps の判定を「受理」「差し戻し」「未確認」のいずれかで書ける。

### M3 トップバーのコンテキストメニュー(P2)

- 説明: Tempo・Song Position・Pattern Selector の右クリックでメニューが画面に出て、項目を選ぶと engine に届き、部品の値が変わる。
- 完了の条件:
  1. 右クリックで、メニューが画面に出る(前後の画面の差が、クリック位置の近くに出る)。
  2. 項目を選ぶと、engine が WM_COMMAND を受け取る(engine のログに出る)。
  3. 3 つの部品それぞれで、メニューの項目を選んで値が変わったことを実測する。

### M4 FL に必要な物の配布

- 説明: FL Studio が必要とする物(インストーラ全件の一覧、FLEngine、言語パック、テーマ、プロジェクトテンプレート)を揃え、起動前に取る物と、起動後にバックグラウンドで取る物に分ける(台帳 L-035)。最初の 1 件は Fruity Balance。
- 完了の条件:
  1. インストーラ全件の一覧が main にあり、件数と SHA-256 の検査が通る。
  2. 起動前に取る物と、起動後に取る物の区分が実装され、Fruity Balance が起動後に届く。
  3. 起動時に見つからなかったファイルが 0 件(記録の仕組みで確かめる)。
  4. 言語・テーマ・テンプレートが、一覧と件数が一致する。

### M5 内蔵のエフェクトとインストゥルメント

- 説明: 内蔵のエフェクト(Plugins の Effects 約 90 件)とインストゥルメント(Generators 約 51 件)を、1 プラグイン 1 wasm で起動後に届ける。OpenGL を使う VFX 系は後回し(台帳 L-034)。件数は依頼者の申告で、インストーラの一覧で確かめる。
- 完了の条件:
  1. OpenGL を使う VFX 系を除く全件が、起動確認(engine-idle・standIn が false・error が null)を通る。
  2. 全件が、起動後の取得で届く。
  3. 種類ごとに 1 件以上が、UI から選べる(M3 の後)。
  4. VFX 系(OpenGL)は後回し。依頼者が着手を決めたら、子 039 で 1 プラグイン 1 wasm で入れる(この完了の条件の対象は、後回しを解いた場合のみ)。

### M6 外部プラグイン

- 説明: Serum 2・OTT・Vital を、既定の経路(オプトイン無し)で読み込み、1 ブロックの音声を処理する(台帳 L-002・L-035)。
- 完了の条件:
  1. 3 件が既定で読み込まれ、1 ブロックの音声を処理する(実測)。
  2. VST3 の link が既定で有効になっている(オプトインが無い)。

### M7 エンジンの性能(P3 のホットパス)

- 説明: P3 の再生中に実行される命令の内訳を実測し、直接 wasm でない関数のうち命令数が多いものを、一括で直接 wasm にする。1 関数 1 タスクに戻さない(台帳 L-037)。
- 完了の条件: P3 の再生中の命令数のうち、直接 wasm でない関数の割合が、依頼者が決める目標値以下(目標値は QUESTIONS 9)。

### M8 起動 10 秒以内とサイズ(P1)

- 説明: 起動(ページを開いてから engine-idle まで)を、runner で 10 秒以内にする。起動前に取る量を決めて、サイズの目標を立てる。
- 完了の条件:
  1. 起動の中央値(n=3)が 10 秒以内。
  2. 起動前に取る量が、依頼者が決めた予算以内(予算は QUESTIONS 8)。
