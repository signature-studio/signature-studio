## 2. 境目(採用段が変わる所)

DPI は整数。隣り合う 2 点で採用段が変わった所は、その間を 0.01 刻みで測った(上の「精密化」の行)。

| 境目 | 手前の DPI(採用段) | 後の DPI(採用段) | 表の from(DPI) | 測った DPR(手前 → 後) |
|---|---|---|---|---|
| 100 → 125 | 108(100) | 109(125) | 109 | 1.13 → 1.14 |
| 125 → 150 | 131(125) | 132(150) | 132 | 1.36 → 1.37 |
| 150 → 175 | 156(150) | 157(175) | 157 | 1.63 → 1.64 |
| 175 → 200 | 179(175) | 180(200) | 180 | 1.86 → 1.87 |
| 200 → 250 | 216(200) | 217(250) | 217 | 2.25 → 2.26 |
| 250 → 300 | 263(250) | 264(300) | 264 | 2.74 → 2.75 |

境目の DPR の位置(DPI ÷ 96): 1.13〜1.14、1.36〜1.37、1.63〜1.64、1.86〜1.87、2.25〜2.26、2.74〜2.75。DPI の 1 刻みで、採用段が 1 段ずつ変わる(DPI 96〜288 の範囲で、上の 6 箇所だけ)。

式(25 % 刻みの最近接や床)では、境目を 1 つでも外す。例: 200 → 250 の境目は、25 % 刻みの中点 225(DPI 216 が 225、DPI 217 が 226)の位置で、中点を越えた所で 250 になる。100 → 125 の中点(112.5)は、DPI 108 で 100 のまま(中点ちょうどは下)、137.5 の中点(132)は 150 になる(中点ちょうどは上)。境目の規則を式として決めるための根拠は、この実測では得られない。判定は表で持つ(式は使わない)。

## 3. 判定の表(`tools/feat-c1-hidpi/fl-scale-steps.json`)

```json
[
  {"from": 96, "scale": 100},
  {"from": 109, "scale": 125},
  {"from": 132, "scale": 150},
  {"from": 157, "scale": 175},
  {"from": 180, "scale": 200},

```

DPI d の採用段は、from ≤ d の最後の要素の scale。表は 65 点の全てに一致する(道具の照合で bad 0)。

## 4. 未確認

- この表は、DPR 1.00〜3.00 の 65 点と境目の精密化による。0.01 刻みの全点を測ったのではない。境目の間で、採用段が 2 回変わる(両端が同じで中間だけ違う)ことは、測っていないので否定できない。
- 採用段が DPI だけで決まるかは、DPI が同じで DPR の違う点(例 1.13 と 1.12 は DPI 108)が同じ段だったことで確かめた。ほかの要因(画面の大きさなど)は、この測定では動かしていない。
- Windows の実機の FL の段は、この機械では確かめられない。
