### 3. 既定の経路: 案 A(プラグインの Worker)を選ぶ

- 案 B(xmod)は、vst-ext.wasm にそのまま使えない。vst-ext.wasm は VST3 ホストの全体(main、独自のメモリ、ファイル表)を持つ emscripten の完全なプログラムである。xmod(app/src/engine/xmod.ts)は、engine のメモリと c.* の関数を import し、f_* を export する部品なので、型が合わない。OTT を案 B で使うには、OTT の code を engine の hybrid で lift し直す別の build が要る(#1342 の型。engine.wasm は既に 165 MB)。
- 案 A は、この artifact と、計測の経路(measure.mjs = PluginInstance.start)をそのまま使う。1 インスタンス 1 Worker の設計(decision 0173)に合う。
- 推定: 案 A の方が、plugin の処理を engine の Worker から分けられる(画面と音声の分離の目標に合う)。
