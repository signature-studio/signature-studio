## 3. 止まった所と直した所(順に)

1. 序数 1 の `d2d1.dll!#1`(D2D1CreateFactory)。thunk が lift されず、`fle: unsupported instruction`。
   - 直し: `lift/harness/vst/ordinals-vst.txt`(新規)に `d2d1.dll 1 D2D1CreateFactory fle_imp_ord_d2d1_1` を書いた。`mk_stubs.mjs` が extra-imports の行 `d2d1.dll #1 fle_imp_ord_d2d1_1` を出す。`fe-lift` の `set_extra` は `#<n>` を API として読む(`#` は行頭か空白の後ろのときだけコメント)。
   - 答え: `D2DERR_NO_HARDWARE_DEVICE`(0x8899000B)、`*ppIFactory = NULL`。`vst3a_imp.c` の `fle_imp_ord_d2d1_1` を、この HRESULT を返すように直した。
   - 呼ばれたか: 前回の run のログで、InitDll の中の呼び出しを確認した(`vst3a: D2D1CreateFactory(type 1) -> D2DERR_NO_HARDWARE_DEVICE`)。今回は測定の stderr に出ない(`vst3a:` の行は測定の出力に含まれない)。ただし、InitDll は 1 を返して起動まで進んだので、この答えの経路を通っている。
2. 残りの序数 16 件(d2d1 以外)は呼ばれていない。停止した呼び出しは error として出るので、今回の error は null である以上、起動と 1 ブロックの間には呼ばれていない。止まる形のまま。
3. switch table の case 入口が seed に無い(`indirect call to 0x…… is not a known function entry`)。fe-decode の jumptab は ImageBase 基準の表だけを認識するため、`lea rB,[rip+T]; movsxd rT,[rB+rI*4]; add rT,rB; jmp rT` の形は lift されなかった。
   - 直し: `lift/harness/vst/seeds_scan.mjs` に (c) を足した(表の基準が lea の形。guard の `cmp` で件数を決める。関数の範囲内で 2 件以上)。seed は `seeds/serum2.txt` を作り直した。fe-decode は変えていない(エンジンの lift に影響させないため)。
4. IMessage / IAttributeList / IBStream / スレッドの入口の dispatch 行が無かった。旧い `gen_vst3a.sh` だけが作っていた行を、`mkrows.sh`(build.sh の作る段)に入れた。
5. `IEditController` は component から取れない(`E_NOINTERFACE`)。class ID から作って初期化し、connect・setComponentHandler・bus・setupProcessing・setActive・setProcessing まで通った(旧い harness の正常な経路)。
6. TLS の callback: 前回の差分で、DllMain の前に DLL_PROCESS_ATTACH で呼ぶ(`TLS callback 0 at 0x29a50f8 (DLL_PROCESS_ATTACH) returned`)。
7. イベント入力を持つ plugin に、最初のブロックで note-on(中央の C。強さ 100/127)。
8. 序数の IAT の口(`main_vst_ext.c`): 応答表の `#<n>` の VA を先に使う。無ければ従来の停止。
9. **マージ後の停止(今回の直し)**: #1389 で `lift/runtime/fle_clip.c` が `fle_clip_host_write` を import するようになった。プラグインの wasm はそれを要求し、worker の import 表(`app/src/plugins/ott-host.ts`)に無いので、`LinkError: ... "fle_clip_host_write": function import requires a callable` で instantiate が落ちた。直し: 表に no-op を 1 行足した(プラグインにはページのクリップボードへの経路が無いので、書かれた文字列は捨てる)。wasm の import は、これで全部揃った(`WebAssembly.Module.imports` で列挙して確認。`fle_clip_host_read` は未 import、`fle_win_api_trace_on` は weak)。
