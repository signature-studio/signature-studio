## 6. ポインタの送り方(選択と理由)

- 送り: CDP `Input.dispatchMouseEvent`(`mouseMoved`、ボタン無し)を、応答を待たずに送る(未応答の上限 256)。起きるたびに、その時刻までに due の分をまとめて送る(バッチ)。`setTimeout` の一回ごとの送りには頼らない(タイマーの解像度で頻度が落ちるため)。送りの形は `tools/p2-frames/measure.mjs` の `pointerLoop` と同じ。
- 経路: 部屋(1836×1056 CSS px)の中央を中心にした半径 400 CSS px の円を、1 秒に 1 周。1200 Hz で 1 件あたり約 2.1 CSS px(DPR 1.7647 で約 3.7 物理画素)。ボタンは押さない。
- 頻度: 公称は `--hz` の 1.2 倍(1000 Hz なら 1200/s)。60 秒で 72000 件を送り、CDP のエラーは 0。未応答の最大は 45〜75 件(上限 256 に届かない)。
- 届きの確認: ページの `pointermove` の件数(`getCoalescedEvents()` の件数)を 1 秒ごとに数える。判定は窓の全ての秒で `--hz` 以上。1000 Hz 系の 6 回の最小は 1189〜1197。
- 送りが届かない時の代替(複数の接続・`timestamp`・`PointerEvent` の合成など)は使わなかった。届いている。
