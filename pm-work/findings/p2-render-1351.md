## 2. どこが画面の画素数に比例していたか

実測(表 A・B):

- 提示 1 回の描画は、全面の消去と、全面の大きさの窓の四角形の描画だった(描画の画素 = 全面 6.04 Mpx。窓は 1 つだけ描かれる)。描き直す範囲は、変化の有無によらず画面全体。
- GPU プロセスの CPU は、提示 1 回あたり DPR 1 で 137 ms(1.94 Mpx)、DPR 1.7647 で 425 ms(6.04 Mpx)。比は 3.1 で、画素の比と同じ。1 秒あたりでは両方とも約 2 コアで、提示の回数 × 画素数が両方で約 28 Mpx/s(14.5 × 1.94 と 4.5 × 6.04)。GPU の CPU は、全面の描画の量に比例していた(SwiftShader のソフトウェア描画での値。推定の根拠は実測)。
- レンダラの compose は DPR 1 で 1.16〜1.21 ms、DPR 1.7647 で 1.16〜1.41 ms で、画面の大きさに比例していない。draw は 0.06〜0.11 ms で一定。put は 0.37〜0.41 ms(DPR 1)から 0.95〜1.19 ms(DPR 1.7647)に増え、転送の画素とともに増えた。
- 転送は、窓ごとの変化の外接矩形の分だけだった(全面ではない。転送の画素は画面の 18〜39%)。ただし外接矩形は変化の画素より大きい(runtime の sh_trim が窓ごとに 1 つの矩形を返す)。

結論: 「画面全体の画素数に近い形で増えている」は、GPU プロセス(全面の消去と全面の窓の描画)については当てはまった。レンダラ側の compose と draw は当てはまらない。put は転送の量に比例した。提示 1 回の CPU の増加(DPR 1 の 74 ms → DPR 1.7647 の 224〜240 ms)は、主に提示の回数の減少(14.5 → 4.5 回/秒)による。

## 7. 残る要因と限界

1. `cpuPerPresentMsP95` の基準(4.2 ms)に届かない理由: レンダラの描画の経路は、提示 1 回あたり compose 0.6〜0.7 ms・put 0.6 ms・draw 0.07 ms(変更の後)で小さい。`cpuPerPresentMs` の大半は、エンジン(ゲストの wasm。DedicatedWorker の約 0.9〜1.3 コア)を、提示の回数で割った値。提示が 13 回/秒なら、エンジンだけで約 100 ms/提示になる。4.2 ms にするには、エンジンの CPU を大きく減らすか、提示を約 120 回/秒にする必要がある(推定。この指標の設計は PM が見直す)。
2. `inputToPresentMsP95` の基準(17 ms)に届かない理由: 描画の経路の費用は 1〜2 ms(compose と put)で、入力から提示までの 140〜223 ms の大半は描画の外。エンジンの入力の受け取り(スケジューラの点)と、ゲストの計算の時間が残る(推定。この測定では分けられない。#0280・#1349 の範囲)。
3. 負荷 b の入力: ページが受けた pointermove は、負荷 b で 1 秒あたり 735〜764 件(1000 未満)。変更の前後・DPR 1 と 1.7647 で同じ。音の再生中にブラウザが移動を合体させている、またはページの主スレッドの負荷による(推定。原因は分けられていない)。このため負荷 b は `valid` が false で、受け入れが通らない理由の一つ。
4. 窓ごとの外接矩形: runtime の変化の矩形は窓ごとに 1 つ(lift/runtime/fle_desk.c の sh_trim)。負荷 a・b では、転送の画素が画面の 10〜39%。変化の画素ごとに区切るには、lift/runtime の変更と wasm の再ビルドが要る(今回は行っていない)。
5. 実 GPU での挙動は未確認: `preserveDrawingBuffer: true` の下では、実 GPU のブラウザが提示のたびに描画バッファを複写しうる(画面全体の複写。転送の量より軽いと推定)。ここで測ったのは SwiftShader の値で、実機の GPU の値ではない。
6. 窓の配置・重なり・領域が変わった提示は、全面を描く(移動・リサイズ・前後の入れ替え)。今回の負荷では起きていない(未確認の経路)。
7. 縁(`edgeWidth`)は、`deskDumpBase64(true)`(desk-dump の peek)で測る。これはシーンを全面で描き直して読み出す経路で、canvas に描く経路(今回の変更の対象)は通らない。値は #1347 の記録と同じ 2.626 で、画質は落としていない。
