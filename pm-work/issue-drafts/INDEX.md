# Issue の下書き(索引)

承認(台帳 L-040)まで、GitHub に書き込まない。この下書きは、依頼者の承認を得た後に、Milestones・Issues・Sub-Issues・ラベルとして作る。

- 1 ファイル = 1 つの Issue。ファイルの先頭の front matter は、起票の属性(`draft`・`title`・`type`・`milestone`・`parent`・`blocked_by`・`labels`・`size`・`needs_owner`)。`---` より後が、Issue の本文。
- Milestones の一覧と説明: `pm-work/milestones.md`。ラベルの案: `pm-work/issue-drafts/LABELS.md`。依頼者への入力の一覧: `pm-work/issue-drafts/QUESTIONS.md`。依存図: `pm-work/issue-drafts/GRAPH.md`。
- 件数: Epic 11 件、task 28 件(合計 39 件)。想定の所要の合計は、task 28 件で 146 時間(見積り)。
- 本文の「読む物」は、リポジトリの中で実在するパスだけを書く。旧のパス(`queue/`・`driver/`・`ci/tasks/`)は、作業者に読ませない。
