## 目的

完成の条件の最終の判定。6 つの課題(C-1〜C-6)と、P1・P2・P3 の最終の実測を、同じ道具で行い、判定の語(「受理」「差し戻し」「未確認」)を付けて報告する。

- 判定の基準(各子 Issue の基準を、ここでまとめる):
  - C-1 HiDPI: 拡大率 1・1.5・2 で canvas の幅と高さが CSS × 拡大率(±1 画素)。(#{{006}})
  - C-2 描画の分離・P3: #{{002}} の測定で、分離の前後の音声の余裕の差が報告されている。#{{040}} の受け入れで、UI の負荷をかけても underrun が 0(n=3)。(#{{002}}・#{{040}})
  - C-3 必要な物: 言語・テーマ・テンプレートが、インストーラの一覧と件数が一致し、見つからないファイルが 0。(#{{013}}・#{{016}}・#{{017}})
  - C-4 内蔵: 全件(VFX 系を除く)が起動確認を通り、起動後に届く。VFX 系は、#{{039}} で入れる。(#{{019}}〜#{{023}}・#{{039}})
  - C-5 外部: Serum 2・OTT・Vital が既定の経路で読み込まれ、1 ブロックの音声を処理する。(#{{025}}〜#{{029}})

  - P2: 120 fps と、入力から画面の p95 が 17 ms 以下。120 fps は、表示の上限を外す起動の引数で測る。(#{{007}}・#{{008}})
  - P3: 所定のプロジェクト(#{{004}} の demo)で、Song Mode の underrun が 0(n=3)。(#{{004}})
- 定義の出典(旧 ci タスクの記述による)の文書 `docs/ops/fidelity-and-performance.md` は、リポジトリに無い。

## やること

1. 子の Issue の結果を、判定の表にまとめる(課題・基準・測定の値・判定)。判定は、出力の行で示す。
2. 最終の実測を行う。P1(3 回)、P2(拡大率 1 と 2)、P3(#{{004}} のプロジェクト、n=3)。同じ道具で行う。
   - 追加の条件(依頼者の実機の条件。2026-11-23): (0) 起動して 10 秒後、再生もマウス操作も無い状態で、直近 60 秒の途切れが 0(n=3。#{{109}} の段 0)。(a) 画面は CSS の大きさ 1836×1056・DPR 1.7647 の画面(guest の画面は 3240×1863 の物理画素)。(b) DPR 1・1.25・1.5・1.7647・2 の各々で、`tools/feat-c1-hidpi/measure-size.mjs`(#{{107}} が作り、#{{108}} が拡張する)の判定を通す。縁の遷移の幅は 2 画素以下(拡大されてぼやけた画面は不可)。UI の CSS の大きさは DPR 1 と ±5% 以内。(c) P3 は、再生しながら、ポインタを 1000 Hz 以上で動かし続ける 60 秒の `underrunDelta`(#{{109}} が作る `tools/p3-audio-probe/measure-live.mjs`。`inputRateOk` が true であること)を、DPR 1.7647 で n=3。
3. 判定の表を報告に書く。「受理」でない物は、理由を書く。
4. 判定の確認の道具 `tools/final-verify/run.sh` を作り、上の基準を全て確かめる。run.sh の基準は、この本文の基準と一致させる。

## 受け入れ

```accept
bash tools/final-verify/run.sh
```

判定の基準: run.sh の終了コードが 0(C-1〜C-6 の全てが受理。P1・P2・P3 の最終の値が基準を満たす)。run.sh の判定の数値は、この本文の「判定の基準」と一致していること。

## 報告の規則

- 1 行目は「実エンジン: <何を実行し、どの出力を観測したか>」で始める。
- 測定の値には「runner の値。この機械とは別枠」と書き、nproc と loadavg を添える。
- 「達成」と書かず、「受理」「差し戻し」「未確認」のいずれかにする。出力の行を付ける。
- 判定の表(課題・基準・測定の値・判定)を報告に書く。判定が「受理」でない課題は、理由を書く。
- 耳の確認は行わない。「音が途切れない」とは書かず、underrun の数で書く。

## 制約

- 製品に新しい環境変数・#ifdef・URL パラメータ・ビルド変数を足さない。
- 依頼者の個人のプロジェクトを、リポジトリに入れない。
- ベンダー名と Cloudflare の識別子を書かない。
- sleep・timeout・nohup・末尾の `&` は使わない。
